# Limitations

## Overview

AI Music Coach is a practice companion that helps beginners track progress and build confidence. It's important to understand what this product **is not** and **cannot do** at this stage.

## Current Technical Limitations

### No Real Audio Analysis
**What we claim**: Audio metrics can be manually entered for practice sessions.

**What we DON'T claim**:
- Real-time pitch detection
- Chord recognition
- Strumming pattern analysis
- Audio waveform analysis

**Why it matters**: The scores you see are based on manually entered metrics or demo data. We cannot actually "hear" your playing.

### No Real Vision Analysis
**What we claim**: Vision metrics can be manually entered for practice sessions.

**What we DON'T claim**:
- Real-time posture detection
- Finger placement detection
- Hand position analysis from camera
- Strumming form analysis from video

**Why it matters**: We cannot actually "see" your playing. Camera access is not yet implemented for real analysis.

### No AR Guitar
**What we claim**: This is a practice tool with educational feedback.

**What we DON'T claim**:
- AR guitar overlay
- Virtual guitar in your space
- Finger placement guides
- Real-time form correction

**Why it matters**: There is no augmented reality component. This is a standard app, not an AR experience.

### Readiness Score Is Educational Estimate Only

The Readiness Score is calculated from:
- Manually entered audio metrics
- Manually entered vision metrics
- Session duration and frequency
- Rhythm consistency data

**Important clarifications**:
- It does NOT certify musical skill
- It does NOT measure actual guitar proficiency
- It does NOT replace professional assessment
- It does NOT guarantee readiness for any skill level

**What the score means**: A higher score indicates more consistent practice and better self-reported metrics. It's a measure of practice habit, not musical ability.

## What This Product Is NOT

### Not a Guitar Teacher
We do not replace human instruction. Our feedback is:
- Rule-based (deterministic, not AI)
- Beginner-friendly (but not expert guidance)
- Practice-focused (but not curriculum-based)

### Not a Certification Program
The Readiness Score does not:
- Certify skill level
- Grant credentials
- Provide official assessments
- Replace music exams

### Not a Complete Guitar Education
This product does not teach:
- Music theory
- Advanced techniques
- Songwriting
- Performance skills

### Not an AR Application
This is a standard web/mobile application. There is no:
- Camera-based form analysis
- Virtual guitar overlay
- Spatial AR experience
- Motion tracking

## Data Limitations

### Demo Data
When using demo mode, all data is synthetic:
- 10 pre-generated sessions
- Realistic but artificial metrics
- Simulated progress over time

**Demo data should NOT be used to evaluate actual product capability.**

### Manual Entry
All metrics in the current version are manually entered:
- No automatic detection
- No sensor integration
- No real-time analysis

**This means the scores reflect self-reported data, not objective measurement.**

## Known Gaps

### Missing Features
1. **Real camera analysis** - Cannot detect posture from video
2. **Real microphone analysis** - Cannot detect pitch from audio
3. **Chord recognition** - Cannot identify chord shapes
4. **Finger placement** - Cannot detect exact finger positions
5. **AR guitar** - No augmented reality features
6. **User authentication** - No persistent user accounts
7. **Data persistence** - Sessions reset on refresh (MVP)

### Behavioral Gaps
1. **No adaptive learning** - Rules are static, not personalized over time
2. **No curriculum** - No structured lesson progression
3. **No assessment** - No way to verify skill level
4. **No social** - No sharing or community features

## What We Promise

### We Promise To:
1. Be transparent about what we can and cannot do
2. Never claim to replace human teachers
3. Never claim to certify musical mastery
4. Keep data local and private
5. Provide honest confidence levels
6. Clearly label demo data

### We Promise NOT To:
1. Claim real-time audio/vision analysis
2. Claim AR features
3. Claim chord recognition
4. Claim certification authority
5. Make medical or health claims
6. Oversell the product's capabilities
